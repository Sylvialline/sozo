# 2024-8 Programming 生成数据包

本数据包依据题目 PDF 英文部分第 8-10 页生成，覆盖题目要求的全部文件：`data1a.txt` 到 `data5c.txt`。所有矩阵都满足：

- 元素为 `-9` 到 `9` 的整数；
- 任意一行、任意一列的非零元素数均不超过 10；
- 每个矩阵的非零元素总数不超过 `10^6`；
- 第 4(b) 问的 `C`、`D` 各自非零元素数不超过 1000；
- 各文件采用题面规定的 Format 1、Format 2 或 Format 3。

对于题目允许多个最优行的情况，参考程序固定返回编号最小的最优行。这仍然符合题意。

## 目录

```text
2024-8-prog-data-package/
├─ data/                       # 17 个题目数据文件
├─ code/
│  ├─ reference_solver.py      # 正确解题程序，并生成全部参考答案
│  ├─ generate_data.py         # 确定性数据生成器
│  ├─ validate_data.py         # 格式、范围、稀疏约束与答案校验
│  └─ test_reference_solver.py # 400 组随机小规模暴力对拍
├─ answers.txt                 # 便于阅读的参考答案
├─ answers.json                # 机器可读参考答案
├─ data_summary.tsv            # 每个文件的格式、维度和非零元素数
└─ manifest.sha256.tsv         # 数据文件大小及 SHA-256
```

## 使用方法

在本目录下执行：

```bash
python code/reference_solver.py
python code/validate_data.py
python code/test_reference_solver.py
```

重新生成完全相同的数据与答案：

```bash
python code/generate_data.py
```

生成器使用固定随机种子。重新生成后，可用 `manifest.sha256.tsv` 检查数据是否一致。

## 参考程序的核心方法

1. Format 1：逐行累加，时间复杂度 `O(rc)`。
2. Format 2：只遍历非零三元组并累计行和；同时将未出现的行视为和为 0。
3. Format 3 转置：无需真的转置，只累计原矩阵各列之和。
4. `X ★ Y`：按中间下标 `k` 连接 `X(i,k)` 与 `Y(k,j)` 的非零项；对每个 `(i,j)` 维护非零乘积的最小值、最大值和数量。若数量小于中间维数 `m`，说明乘积序列中还含有 0。
5. 固定大小零和矩形：每个非零单元会影响一块“候选左上角区域”。程序按候选顶行扫描，用行事件加入或移除贡献；题目中 `C <= 100`，因此一次事件最多显式更新 100 个候选左列。

## 数据设计说明

- 小规模数据包含全零行、正负抵消、末尾零、稠密乘积等边界情形。
- `10^6 × 10^6` 数据实际使用题面规定的稀疏格式，包含首尾边界坐标和大下标。
- 第 4 问包含同一输出位置经多个 `k` 产生乘积的情形，以检查 `max + min` 是否被误写为求和。
- 第 5 问加入了相邻异号元素与边界簇，覆盖“窗口包含单个非零项”“同时包含抵消项”“完全不含非零项”等情况。
