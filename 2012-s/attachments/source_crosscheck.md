# 英文版与日文版交叉核验记录

核验对象：

- `fy2012_s_en_program.pdf` 第 4-5 页
- `fy2012_s_ja_program.pdf` 第 4-5 页

两份 PDF 均为扫描件。核验时逐页查看原始排版，并按定义、示例、指令表和每个小问逐项比对。

| 核验项 | 英文版 | 日文版 | 结论 |
|---|---|---|---|
| 初始变量 | 仅 `x`、`y` | 仅 `x`、`y` | 一致 |
| 示例程序及解释 | `SET`、`ADD`、`PRN` 示例 | 同一程序与解释 | 一致 |
| 表 1 | `ADD/CMP/JMP/PRN/SET` | 同五条指令 | 一致 |

| 问（2） | 说明固定程序的行为 | 同一程序 | 一致 |
| 问（3）指令范围 | `prog2.txt` 不含 `CMP/JMP`，无需实现 | 同义 | 一致 |
| 问（3）合法性 | 可假定输入 L 代码合法 | 可假定 L 代码无错误 | 一致 |

## 行数差异的处理

英文版的 “less than 100 lines” 对应最多 99 行；日文版的 “100 行以内” 对应最多 100 行。生成的主数据和补充回归数据全部少于 100 行，因而同时符合两版要求。

## 中文题面的解释性补全

原题把 `SUB/CAL` 描述为“记录返回位置”，把跳转描述为“当前命令的 $\alpha$ 行下方”。中文题面将其操作化为：

- 所有相对跳转目标均为“当前指令行号 $+\alpha$”，不是“下一条指令行号 $+\alpha$”。
- `SUB/CAL` 保存的返回位置为该调用指令的下一条指令。
- 嵌套 `SUB` 和递归 `CAL` 必须使用后进先出的返回结构。

这些解释由题中第（2）问的 `JMP -3` 控制流、`BAK/RET` 的“返回”语义以及嵌套/递归要求共同确定。
