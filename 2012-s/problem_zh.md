# 简易语言 L 的解释器

## 题目背景

L 是一种非常简单的程序设计语言。最初的 L 只有表 1 中的 5 条指令，并且只有变量 `x` 和 `y` 可用。

原考试介质提供 5 个 ASCII 文本文件：`prog1.txt`、`prog2.txt`、`prog3.txt`、`prog4.txt` 和 `prog5.txt`，分别用于下面各阶段的测试。

例如：

```text
SET x 1
SET y -2
ADD x y
PRN x y
```

这段代码先令 `x = 1`、`y = -2`，再计算 `x + y` 并把结果保存到 `y`，最后输出 `x` 和 `y` 的值并终止执行。

每条指令均由一个三字母大写操作码和两个操作数 $\alpha,\beta$ 构成。除指令另有要求外，$\alpha$ 和 $\beta$ 都可以是整数常量或变量名。操作数若为变量名，使用该变量当前保存的整数值。

## 表 1：L 的基础指令

| 指令 | 语义 |
|---|---|
| `ADD α β` | 把 $\alpha$ 的值加到 $\beta$ 中，即令 $\beta \leftarrow \alpha+\beta$。$\beta$ 必须是变量名。 |
| `CMP α β` | 若 $\alpha$ 与 $\beta$ 的值相等，则跳过紧随其后的 1 条指令，继续执行再下一条指令；否则继续执行下一条指令。 |
| `JMP α β` | 跳转到当前指令下方第 $\alpha$ 行的指令，即若当前行为 $p$，目标行为 $p+\alpha$。当 $\alpha$ 为负数时向上跳转。$\beta$ 不使用。 |
| `PRN α β` | 输出 $\alpha$ 和 $\beta$ 的值，然后终止程序。 |
| `SET α β` | 把 $\beta$ 的值赋给 $\alpha$，即令 $\alpha\leftarrow\beta$。$\alpha$ 必须是变量名。 |

## 问题

### （1）读取并输出每行的第一个操作数

文件 `prog1.txt` 中保存了一段 L 代码。编写程序读取该文件，并依次输出每一行的第一个操作数。

例如，若某一行为：

```text
SET x 1
```

则第一个操作数为 `x`，第二个操作数为 `1`，因此应输出 `x`。

### （2）说明给定程序的行为

说明下面这段 L 代码的执行过程和最终行为：

```text
SET x 1
SET y 0
ADD x y
ADD 1 x
CMP x 10
JMP -3 0
PRN x y
```

### （3）实现基础解释器

编写一个程序，读取并执行 L 代码，并用 `prog2.txt` 测试。

- `prog2.txt` 不使用 `CMP` 和 `JMP`，因此本问不要求实现这两条指令。
- 可以假设输入的 L 代码始终合法。
- 关于代码行数，英文版原题写的是“少于 100 行”，日文版写的是“100 行以内”。本题数据遵守更严格的限制：少于 100 行。

### （4）支持全部基础指令和任意变量名

扩展第（3）问的程序，使它支持表 1 中的全部 5 条指令。

同时，将任意由小写英文字母 `a` 到 `z` 组成的非空单词视为合法变量名。例如，`i` 和 `count` 都是变量名。用 `prog3.txt` 测试程序。

### （5）支持可嵌套的子程序调用

继续扩展解释器，加入表 2 中的 `SUB` 和 `BAK` 指令，并允许子程序调用嵌套。用 `prog4.txt` 测试程序。

## 表 2：`SUB` 与 `BAK`

| 指令 | 语义 |
|---|---|
| `SUB α β` | 记录返回位置，并跳转到当前指令下方第 $\alpha$ 行的指令；$\alpha$ 为负数时向上跳转。返回位置是该 `SUB` 的下一条指令。$\beta$ 不使用。 |
| `BAK α β` | 返回最近一次尚未返回的 `SUB` 所记录的位置。$\alpha$ 和 $\beta$ 均不使用。 |

$\alpha$ 和 $\beta$ 都可以是整数常量或变量名。要支持嵌套调用，返回位置必须按后进先出的顺序保存。

### （6）支持局部变量、递归函数和返回值

继续扩展解释器，加入表 3 中用于函数调用的 `CAL` 和 `RET` 指令，并用 `prog5.txt` 测试程序。

- 从执行 `CAL` 进入函数起，到执行对应的 `RET` 返回为止，函数中使用的变量必须作为该次调用的局部变量处理。
- 不同函数调用以及递归调用的局部变量互不干扰；返回后，调用者原有变量的值保持不变。
- 函数必须可以递归调用。
- 本次函数调用的实参在函数返回前可通过特殊变量 `in` 取得。
- 最近一次已经返回的函数调用的返回值可通过特殊变量 `out` 取得。函数返回后，该返回值写入调用者当前作用域的 `out`。

## 表 3：`CAL` 与 `RET`

| 指令 | 语义 |
|---|---|
| `CAL α β` | 记录返回位置，创建一次新的函数调用，并跳转到当前指令下方第 $\alpha$ 行的指令；$\alpha$ 为负数时向上跳转。返回位置是该 `CAL` 的下一条指令。$\beta$ 的值作为函数实参，并成为新调用中 `in` 的值。 |
| `RET α β` | 以 $\alpha$ 的值作为函数返回值，销毁当前调用的局部作用域，并返回最近一次尚未返回的 `CAL` 所记录的位置；$\beta$ 不使用。返回值写入调用者作用域的 `out`。 |

$\alpha$ 和 $\beta$ 都可以是整数常量或变量名。函数调用信息和局部作用域也必须按后进先出的顺序保存。

## 本数据包采用的输出约定

原题只要求“输出”，没有规定空白格式。为了使标准答案可以逐字比较，本数据包统一采用以下格式：

- 第（1）问每个第一个操作数单独占一行。
- `PRN α β` 输出两个十进制整数，中间恰好一个 ASCII 空格，末尾换行。
- 每个 L 程序执行到第一条实际执行的 `PRN` 时立即结束。

## 双语版交叉核验说明

本中文题面逐项对照了英文版与日文版原题。除第（3）问的行数表述分别为“少于 100 行”和“100 行以内”外，问题正文、示例程序、各指令语义、测试文件名及六个小问的要求一致。本数据包中的所有程序均少于 100 行，因此同时满足两种表述。
