# 合成データについて

这是一套根据试题文字自行构造的练习数据，**并非考场 USB 中的真实文件**。

## 推测的数据规模

试题没有给出显式上限。考虑到考试要求考生在有限时间内完成几何栅格化、连通分量和最短路，数据采用以下保守而有区分度的范围：

- 图形数量：约 6 到 3001 个；计数题包含一个 3000 级压力样例。
- 坐标：主要位于 0 到 2000；需要完整绘图的题目主要控制在约 0 到 900。
- 圆半径：主要为 1 到 96。
- 栅格规模：最短路与连通分量数据控制在几十到数百格的边长，适合常规 O(W×H) 或 O(W×H log(W×H)) 解法。

这些范围是针对入试实技题难度与 4 小时考试时长的推断，不代表官方约束。

## 覆盖的 corner cases

- 三类图形混排，首尾类型不同，文件长度跨越多个数量级。
- 后画图形覆盖先画颜色；`data3a.txt` 最后一笔将所有已画区域覆盖为黑色。
- 半径 1 的圆、斜率绝对值大于/小于 1 的线段、反向端点、恰好经过网格角点的线段。
- 包围盒的 x/y 极值由不同图形、不同位置产生，右下角不依赖最后一个图形。
- 仅对角接触的同色格不连通；某颜色完全不存在时最大连通分量为 0。
- 问(5)包含：零异色可达、为了减少异色格必须明显绕路、终点颜色与起点不同、包围盒角点为白色且最优路径必须走出包围盒。

## 几何解释

- 长方形包含 `x1..x2`、`y1..y2` 的所有格（端点格包含）。
- 圆：格子的开内部与圆的开内部有交集即上色；相切而无内部交集不计。
- 线段：格子的开内部与线段有交集即上色；只碰到格边或格角不计。
- 问(5)：先最小化“与起点格颜色不同的格子数”，再在这些路径中最小化路径包含的格子数。起点本身长度计 1。
- 画布无限且包围盒外全白。验证程序搜索包围盒外扩一格；统一白色的外部区域中，更远的绕行不会优于贴着外框的路径。

## 文件

- `data1a.txt` ... `data5d.txt`：16 个练习输入文件。
- `standard_answers.txt`：按题目要求排列的标准答案。
- `answers.json`：机器可读答案。
- `audit_metrics.csv`：每个文件的额外检算指标。
- `verify_answers.py`：独立读取 data 文件并重新计算答案的验证程序。
