# 英文版与日文版交叉核验记录

核验页：两份 PDF 的第 4 页为完整问题正文，第 5 页为图 1 和图 2。

| 核验项 | 英文版 | 日文版 | 结论 |
|---|---|---|---|
| $d$-格点 | $\{(dp,dq)\mid p,q\in\mathbb Z\}$，明确整数包含负数 | 同一定义，同样明确包含负数 | 一致 |
| $A(d,R)$ | 区域 $R$ 内 $d$-格点数量 | 同义 | 一致 |
| $R_0$ | $0\le x\le10$ 且 $0\le y\le10$ | 同一闭不等式 | 一致 |
| 示例 | $A(1,R_0)=121$ | 同一数值 | 一致 |
| $R_1$ | 圆心 $(5,5)$、半径 5 的闭圆盘 | 同一闭不等式 | 一致 |
| 问（2） | $A(d,R_1)/A(d,R_0)\times1/4$ | 同一表达式 | 一致 |
| 科赫步骤 1 | 每条线段三等分 | 同义 | 一致 |
| 科赫步骤 2 | 以中段为底边向外画正三角形 | 同义 | 一致 |
| 科赫步骤 3 | 删除该正三角形底边 | 同义 | 一致 |
| 初始顶点 | $(0,0),(10,0),(5,5\sqrt3)$ | 同一组顶点 | 一致 |
| $K_n$ | 迭代 $n$ 次后的图形内部，包含边界 | 同义且明确包含边界 | 一致 |
| 问（3） | 输出 $K_2$ 面积，必须为浮点数 | 同义 | 一致 |
| 问（4） | 给定正整数 $n$，计算 $K_n$ 面积，必须为浮点数 | 同义 | 一致 |
| 问（5） | 给定浮点数 $d$，计算 $A(d,K_2)$ | 同义 | 一致 |
| 问（6） | 给定浮点数 $d$ 和正整数 $n$，计算 $A(d,K_n)$ | 同义 | 一致 |

两版都没有给出 $d$ 的正性、精度或范围，也没有给出 $n$ 的上界；只有问（4）、（6）明确要求 $n$ 为正整数。多测范围和逐字输出格式详见 `problem.md`，属于数据包约定。
